Gmail
  1. Click Copy signature.
  2. Gmail → ⚙️ → See all settings → General → Signature → Create new.
  3. Paste into the box, scroll down and click Save Changes.
Outlook (new Outlook / web)
  1. Click Copy signature.
  2. Settings → Accounts → Signatures → New signature.
  3. Paste, name it "SGFX", set it as the default for new messages and replies, then Save.
Apple Mail
  1. Open this page in Safari and click Copy signature.
  2. Mail → Settings → Signatures → +.
  3. Untick "Always match my default message font", then paste into the right-hand panel.
